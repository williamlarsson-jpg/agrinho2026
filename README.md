🌱 Agro Forte, Futuro Sustentável
📖 Sobre o Projeto
O tema central do trabalho é "O Agronegócio Consciente e Sustentável", abordando a importância da inovação tecnológica, da sustentabilidade e do agronegócio para o desenvolvimento da sociedade.
Durante o desenvolvimento, foram utilizados conhecimentos de HTML, CSS, JavaScript e ferramentas de Inteligência Artificial Generativa. A IA auxiliou na criação da estrutura inicial do site, que posteriormente foi analisada, adaptada e personalizada pelo aluno conforme suas ideias e objetivos.
🎯 Objetivos
Desenvolver competências em programação web.
Utilizar a Inteligência Artificial como ferramenta de apoio ao desenvolvimento.
Aplicar conceitos de acessibilidade e experiência do usuário (UX).
Promover reflexões sobre sustentabilidade e inovação no agronegócio.
Exercitar criatividade, análise crítica e personalização de código.

🤖 Utilização da Inteligência Artificial
A Inteligência Artificial foi utilizada como ferramenta de apoio para geração da estrutura inicial do projeto.
Prompt utilizado
Contexto: Atue como um Desenvolvedor Full-Stack focado em UX e Acessibilidade. Crie um site de página única (Landing Page) sobre Agro Forte, Futuro Sustentável.

Arquitetura de Arquivos
Entregue o código dividido em três arquivos:
index.html
style.css
script.js
No HTML, utilize:
Tags semânticas (header, main, section, article e footer);
Atributos ARIA para acessibilidade.

Design System (CSS)
Utilize Variáveis CSS (:root) para definir:
Paleta de cores;
Espaçamentos;
Arredondamentos (--radius).
O layout deve ser:
Responsivo (Mobile First);
Desenvolvido com CSS Grid e Flexbox.
Implementar:
Modo de Alto Contraste acionado pela classe .high-contrast;
Animações suaves de entrada das seções (Scroll Reveal).

Camada de Inteligência (JavaScript)
Gestão de Dados
Não inserir conteúdos repetitivos diretamente no HTML.
Criar arrays de objetos no JavaScript para renderização dinâmica de:
Cards;
Galerias;
Conteúdos similares.
Acessibilidade
Implementar funções para:
Aumentar fonte;
Diminuir fonte;
Melhorar a experiência do usuário.
Componentes
Implementar:
Carrossel funcional;
Sistema de abas ou acordeões expansíveis.

Flexibilidade e Organização
O código deve ser modular e comentado.
Comentar especialmente as áreas responsáveis por:
Cores principais;
Grid Layout;
Responsividade.
A entrega deve apresentar:
Estrutura HTML;
CSS;
JavaScript.
Personalização
Após a geração inicial por Inteligência Artificial, foi realizada adaptações próprias, incluindo alterações de layout, conteúdo, identidade visual, cores, organização das informações e recursos adicionais.
